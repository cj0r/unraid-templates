# Security

This repository holds Unraid Docker templates (XML files) and nothing that runs on its own. A template tells Unraid which image to pull and which settings to offer, so the things worth reporting here are a template that points at the wrong image or asks for more access than the application needs.

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately through GitHub instead: on this repository's **Security** tab, choose **Report a vulnerability** (https://github.com/cj0r/unraid-templates/security/advisories/new).

Problems in an application itself belong to that application's repository, each with its own policy:

- [laminator](https://github.com/cj0r/laminator/security/policy)
- [StaffPicked](https://github.com/cj0r/staffpicked/security/policy)
- [LFTP Sync Manager](https://github.com/cj0r/lftp-sync-manager/security/policy)
